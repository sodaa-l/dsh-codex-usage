# 06：本地配置刷新周期并保留最后成功数据

- 状态：已采纳
- 适用范围：Client 自动刷新、故障恢复和浏览器偏好

## 背景

用户需要可控的刷新频率，也需要选择侧栏显示哪些用量。暂时的网络错误不应立即清空已有额度。自动刷新只在侧栏卡片实际挂载且总开关开启时运行，避免关闭侧栏显示后继续轮询。

## 决策

刷新周期、侧栏总开关及 5 小时/每周窗口开关仅保存在当前浏览器的 `localStorage`。刷新周期可选 1、5、15、30 分钟，默认 1 分钟；三个显示开关默认开启。侧栏挂载且总开关开启时立即读取，并在组件存续期间按周期刷新；设置页提供手动刷新。关闭总开关隐藏卡片并停止其轮询；单项开关只隐藏对应额度行，不改变用量查询。相同页面通过自定义事件同步设置，同一来源的其他标签页通过 `storage` 事件重新读取。

Client 请求遇到可重试错误时最多尝试三次，首次后等待 1 秒，第二次后等待 3 秒。若失败但此前有成功窗口，则继续显示最后成功的窗口数据；未登录状态会显示未登录结果，不保留旧额度。退出或组件卸载时清除相关请求与计时器。

## 后果

- 刷新周期和显示开关不在不同浏览器间同步，且没有云端保存。关闭总开关后应无侧栏定时请求；只关闭某一个窗口仍会请求并刷新其余可见数据。
- 旧额度可能在服务暂时不可用时继续显示；内部状态会标记为 stale，但界面按产品决定不显示额外的 stale 警告。
- 调整重试次数、间隔、显示开关或 stale 行为时，应验证请求取消、连续失败恢复、偏好同步、退出登录和组件卸载。
