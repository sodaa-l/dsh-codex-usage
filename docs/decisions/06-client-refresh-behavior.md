# 06：本地配置刷新周期并保留最后成功数据

- 状态：已采纳
- 适用范围：Client 自动刷新、故障恢复和浏览器偏好

## 背景

用户需要可控的刷新频率；暂时的网络错误也不应立即清空已有额度。自动刷新只在侧栏卡片实际挂载时运行，避免设置页单独打开时持续轮询。

## 决策

刷新周期仅保存在当前浏览器的 `localStorage`，可选 1、5、15、30 分钟，默认 1 分钟。侧栏挂载时立即读取，并在组件存续期间按周期刷新；设置页提供手动刷新。相同页面通过自定义事件同步设置，同一来源的其他标签页通过 `storage` 事件重新读取。

Client 请求遇到可重试错误时最多尝试三次，首次后等待 1 秒，第二次后等待 3 秒。若失败但此前有成功窗口，则继续显示最后成功的窗口数据；未登录状态会显示未登录结果，不保留旧额度。退出或组件卸载时清除相关请求与计时器。

## 后果

- 刷新周期不在不同浏览器间同步，且没有云端保存。
- 旧额度可能在服务暂时不可用时继续显示；内部状态会标记为 stale，但界面按产品决定不显示额外的 stale 警告。
- 调整重试次数、间隔或 stale 行为时，应验证请求取消、连续失败恢复、退出登录和组件卸载。
